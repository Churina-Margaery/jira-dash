# Краткий отчёт по тестам

Проверка от **26.10.2026**: **32 теста, все прошли**, ошибок и пропусков нет. Используется встроенный тестовый раннер `node:test`.

## Количество и виды

| Файл | Вид | Количество | Что проверяется |
| --- | --- | ---: | --- |
| `analytics.test.ts` | Модульные | 21 | Шесть метрик, границы гистограмм, единицы времени, повторные открытия, UTC, роли пользователей, нормализация и валидация данных |
| `report.test.ts` | Модульные | 3 | Состав HTML-отчёта, обозначение неполной выборки, экранирование JQL и HTML |
| `integration.test.ts` | Интеграционные | 7 | 6 сценариев с HTTP-сервером: полный путь до отчёта, пагинация, лимит выборки, HTTP 429/401, таймаут, пустая страница; ещё 1 сценарий — чтение и проверка конфигурационного файла |
| `logger.test.ts` | Интеграционный | 1 | Запись в настоящий временный файл, сохранение предыдущих записей, уровни логирования |
| **Всего** | **24 модульных + 8 интеграционных** | **32** | |

В HTTP-тестах JIRA заменена локальным сервером с подготовленными ответами — это тестовая заглушка. Клиент выполняет реальные HTTP-запросы к нему. Один сценарий проверяет цепочку **HTTP → пагинация → JSON на диске → аналитика → HTML**. Временные файлы и сервер удаляются/закрываются после тестов. Реальная Apache JIRA проверялась отдельно запуском приложения.

## Повторный запуск

Из корня проекта:

```sh
npm test               # все 32 теста
npm run test:coverage  # тесты и пересчёт покрытия
```

Подробности по файлам: `coverage/index.html`; числовые результаты: `coverage/coverage-summary.json`. После изменения кода или тестов значения в этом README нужно обновить. Настройки измерения — в `.c8rc.json`; [документация c8](https://github.com/bcoe/c8).
