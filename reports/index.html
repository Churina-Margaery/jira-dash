1. Время от создания до закрытия

Шаг интервала: 2 мес. Для шкалы 1 месяц = 30 дней. Учтено задач: 227. Точные интервалы и количество задач — при наведении на столбец.

JQL

project = "HDFS" AND status IN ("Resolved", "Closed") ORDER BY created DESC, key DESC

Расчёт в приложении: Расчёт по неполной выборке: 500 из 17153 задач проекта HDFS. JQL описывает отбор по всему проекту. Для сейчас закрытых задач из changelog берётся последнее вхождение в группу закрытых статусов, затем вычитается created. При отсутствии перехода используется resolutiondate; при отсутствии обеих дат задача исключается. Повторные открытия учитываются. Полученные длительности группируются в равные округлённые интервалы.

3. Созданные и закрытые задачи по дням

● Создано за день● Закрыто за день● Создано накопительно● Закрыто накопительно

JQL — созданные задачи

project = "HDFS" ORDER BY created DESC, key DESC

JQL — закрытые задачи

project = "HDFS" AND status IN ("Resolved", "Closed") ORDER BY created DESC, key DESC

Расчёт в приложении: Расчёт по неполной выборке: 500 из 17153 задач проекта HDFS. JQL описывает отбор по всему проекту. Создания группируются по created в UTC. Закрытия — по последнему вхождению в группу закрытых статусов из changelog (или resolutiondate при отсутствии перехода), только у сейчас закрытых задач. Пустые дни заполняются нулями, накопительные итоги получаются последовательным суммированием дневных значений.
